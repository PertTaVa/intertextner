# 📚 INTERTEXTNER 

**INTERTEXTNER — Trace characters, places, and events across texts.**  
---
## About the Project
INTERTEXTNER is a minimal working prototype (MVP) for analyzing text intertextuality using **Named Entity Recognition (NER)** with **spaCy**.  
It allows you to compare texts and identify shared entities, highlighting connections between them.

**Key Features:**
- Upload two texts: **Source** and **Comparison**  
- Extract entities (PER, LOC, ORG, DATE, MISC)  
- Display entity matches in a **table** and an **interactive D3.js graph**  
- Color-code nodes by entity type  
- Highlight entities and show **tooltips with text context** on hover  
- Drag nodes with the mouse for easy visualization  

---

## Technologies
- **Python & Flask** — backend  
- **HTML, CSS, JavaScript** — frontend  
- **D3.js** — interactive graph visualization  
- **spaCy & Stanza** — NER extraction (Russian, Finnish, Swedish)

# 📚 📚 INTERTEXTNER MVP

## Описание
Это минимальный рабочий прототип (MVP) для анализа интертекстуальности текста через Named Entity Recognition (NER) с помощью spaCy.  

Проект позволяет:

- Загружать два текста: **Источник** и **Сравнение**.  
- Выделять сущности (PER, LOC, ORG, DATE, MISC).  
- Отображать совпадения сущностей на интерактивном графе D3.js.  
- Цветовое кодирование узлов по типу сущности.  
- Подсветка и tooltip с контекстом текста при наведении.  
- Возможность перетаскивать узлы мышью для удобной визуализации.
